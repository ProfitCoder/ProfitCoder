## 👨‍💻 About me

I'm a second-year Web Application Development student based in Granada, Spain. My projects range from browser games and web apps to Python tools for reviewing accounting data. I document my deployments so other students can reproduce the setup.

- **Frontend** · I work with JavaScript, DOM events, forms, validation and responsive layouts.
- **Backend and databases** · I'm learning PHP and session handling, working with Cloud Firestore, and developing my skills in Java, MySQL and Oracle PL/SQL.
- **Deployment** · I've published projects with GitHub Pages and configured Apache2 virtual hosts on Ubuntu Server in VirtualBox.
- **Automation** · I'm exploring Python for spreadsheet automation, GitHub Actions for deployment, and AI-assisted workflows.

I've also completed a course on using AI with Microsoft 365. My goal is to build and publish web applications backed by well-designed databases.

## 🚀 Featured projects

### 🛒 Tienda Demo

A static storefront with a sample product catalogue, category filters, search and a demonstration cart. I deployed it from Windows to an Ubuntu Server virtual machine running Apache2. The deployment report covers the virtual host for `tienda.local`, VirtualBox NAT port forwarding and updates with `git pull`.

**Stack** · HTML, CSS, JavaScript, Git, Ubuntu Server, Apache2 and VirtualBox

[![Source code](https://img.shields.io/badge/Source_code-24292F?style=flat-square&logo=github&logoColor=white)](https://github.com/ProfitCoder/Tienda_Despliegue)

### 🗂️ WebbApp for Notes

A sticky-note board built with vanilla JavaScript and Cloud Firestore. Users can create, edit, delete and drag notes with a mouse or touch. The app saves note content and positions between visits. The public demo uses a shared database.

**Stack** · HTML, CSS, JavaScript and Cloud Firestore

[![Source code](https://img.shields.io/badge/Source_code-24292F?style=flat-square&logo=github&logoColor=white)](https://github.com/ProfitCoder/WebbApp_for_Notes)
[![Open shared demo](https://img.shields.io/badge/Open_shared_demo-0369A1?style=flat-square&logo=firebase&logoColor=white)](https://profitcoder.github.io/WebbApp_for_Notes/)

### 🍋 LemonSqueezer

An incremental browser game where players squeeze lemons, buy upgrades and automate juice production. It features a pixel-art interface, temporary bonuses and customisation. I built it with [ZaneDevv](https://github.com/ZaneDevv) and [Vimobo](https://github.com/Vimobo) as part of **Lemon Team**.

**Stack** · HTML, CSS and JavaScript

[![Source code](https://img.shields.io/badge/Source_code-24292F?style=flat-square&logo=github&logoColor=white)](https://github.com/ProfitCoder/LemonSqueezer)
[![Play LemonSqueezer](https://img.shields.io/badge/Play_LemonSqueezer-FACC15?style=flat-square)](https://profitcoder.github.io/LemonSqueezer/)

### 🎮 Code Runner

A JavaScript arcade game where players dodge bugs and collect code fragments. It includes increasing difficulty, combos, three lives, keyboard and touch controls, and a high score saved locally in the browser.

**Stack** · HTML, CSS and JavaScript

[![Source code](https://img.shields.io/badge/Source_code-24292F?style=flat-square&logo=github&logoColor=white)](https://github.com/ProfitCoder/HackatonGameJS)
